#  Exercícios com Estruturas de Repetição (while e do...while)

Este repositório contém exercícios desenvolvidos em JavaScript com foco no uso de estruturas de repetição (`while` e `do...while`), além de validação de dados e interação com o usuário.

---

##  1 - Validação de Senha 🔑

O programa solicita que o usuário digite uma senha previamente definida no sistema. Caso a senha digitada esteja incorreta, o sistema continua pedindo novamente até que o usuário informe a senha correta. Quando a senha é validada, o acesso é liberado.

---

##  2 - Soma com Confirmação ✅

O programa solicita números inteiros ao usuário e realiza a soma desses valores. Após cada entrada, o sistema pergunta se o usuário deseja continuar inserindo números. O processo se repete enquanto a resposta for positiva, e ao final é exibida a soma total dos valores informados.

---

##  3 - Jogo de Adivinhação 🔮

O sistema define um número secreto dentro de um intervalo pré-estabelecido. O usuário deve tentar adivinhar esse número. O programa continua solicitando tentativas até que o usuário acerte o valor correto. Ao final, é exibido o número de tentativas necessárias para o acerto.

---

##  4 - Validação de Cadastro 🖥️

O programa solicita o nome de um produto ao usuário. O sistema valida se o nome possui pelo menos três caracteres. Caso a entrada seja inválida, o usuário é informado e deve digitar novamente até que o nome atenda aos requisitos estabelecidos.

---

##  5 - Sistema de Cafeteria ☕

O programa exibe um menu interativo com opções de produtos de uma cafeteria. O usuário pode selecionar itens para adicionar ao pedido, e o sistema acumula o valor total da compra. Caso uma opção inválida seja informada, o sistema exibe uma mensagem de erro. O processo se encerra quando o usuário escolhe finalizar o pedido, momento em que o total da compra é exibido.

---

## 💡 Conceitos Utilizados

- Estruturas de repetição (`while` e `do...while`)
- Condicionais (`if / else`)
- Validação de entrada do usuário
- Controle de fluxo
- Interação com o usuário via `prompt` e `alert`

---

## 🚀 Objetivo do projeto

Desenvolver a lógica de programação por meio de exercícios práticos, reforçando o uso de laços de repetição, validação de dados e tomada de decisão em JavaScript.
